# Swarmtunes

Swarmtunes is a music app for Neuro and Evil covers of songs, as well as official releases and collaborations. It features user accounts, playlists, and songs grouped by streamer.

This repository contains the source code for Swarmtunes' client and guides to help you run it yourself.

Alternatively, you can use Swarmtunes on the [official website](https://swarmtunes.com).

## Contributing

Swarmtunes welcomes contributions! The guides below will help you set up and run Swarmtunes locally.

- [Client setup](https://github.com/AceandGaming/swarmtunes-client/blob/main/setup.md)
- [Server setup](https://github.com/AceandGaming/swarmtunes-server/blob/main/setup.md)

Once you've pushed your changes to your fork, you can open a [Pull Request](https://github.com/AceandGaming/swarmtunes-client/pulls).

I don't check pull requests often, so please message me on [Discord](https://discord.com/channels/574720535888396288/1451487201056653365) after submitting one.
